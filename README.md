# 🎙️ Валерия Ерохина — Сайт студии эстрадно-джазового вокала и фонопедии

> **Премиальный интерактивный веб-сайт преподавателя высшей категории, кандидата педагогических наук и действующей вокалистки Валерии Ерохиной.**  
> Построен с акцентом на научную вокальную физиологию, фонопедию, интерактивные тренировочные модули, WebGL 3D-визуализацию и безупречную адаптивность под мобильные устройства.

---

## 🌟 Ключевые возможности и интерактивные модули

### 1. 🧬 Интерактивный 3D-атлас резонаторов голоса (Three.js & WebGL)
* **Анатомическая 3D-визуализация**: Реальный полупрозрачный 3D-скан головы, шеи и плеч человека (`LeePerrySmith.glb`) с авторским Fresnel/X-Ray шейдером.
* **Внутренние органы голосового тракта**: Трахея с хрящевыми полукольцами, разветвление главных бронхов, разделённые левое и правое лёгкие, куполообразная диафрагма, перстневидный и щитовидный хрящи гортани, истинные и ложные (вестибулярные) связки, надгортанник, нёбный свод и резонаторная маска (носовые и лобные пазухи).
* **Анатомические крошки техник**: Быстрое переключение вокальных режимов (`Головной купол`, `Маска • Микст`, `Нёбо • Субтон`, `Расщепление`, `Гортань • Бэлт`, `Грудная опора`).
* **Живая динамическая проекция (Callout Line)**: Пунктирная линия в реальном времени соединяет активную зону органа в 3D с описательной карточкой вокальной механики.
* **Сэмплированные человеческие голоса**: Воспроизведение реальных гласных с естественным вибрато и точной формантной фильтрацией (воздушный субтон, мощный бэлт, контролируемый драйв).
* **Управление ракурсом**: Свободное вращение мышью/пальцем, масштабирование колесом или кнопками-лупами, вертикальный слайдер панорамирования без перекрытия обзора.

### 2. 🎤 Интерактивный тест голоса с микрофоном в реальном времени
* **Прямой анализ частоты (Pitch Detection)** через Web Audio API с автокорреляционным алгоритмом без внешних бэкендов.
* **Определение диапазона и типа голоса**: Сопрано, Меццо-сопрано, Контральто, Тенор, Баритон, Бас.
* **Индивидуальный калькулятор репертуара**: Подбор 4 известных мировых и отечественных композиций, идеально подходящих под выявленный природный диапазон ученика.
* **Караоке с живым метрономом и нотной подсказкой**: Песни с выбором тональности и темпа.

### 3. 🎹 Интерактивный тренажёр-электропианино
* 4 реалистичных инструментальных банка: **Studio Acoustic Piano**, **Orchestral Strings**, **Concert Harpsichord**, **Church Organ**.
* Поддержка нажатия мышью, тач-скрина и клавиатуры компьютера.
* Визуализация клавиш, ладов и нот в реальном времени.

### 4. 📜 Галерея дипломов и сертификатов
* Карусель с поддержкой горизонтального перетаскивания (drag-to-scroll) на десктопе и плавного свайпа на мобильных экранах.
* Модальное окно просмотра в высоком разрешении с возможностью детального зума.

### 5. ⭐ Отзывы учеников с Яндекс Карт и Авито
* Живой рейтинг 5.0, удобный скролл карточек свайпом/мышью без рывков и размытия.

### 6. 🗺️ Интерактивная карта студии (Новая Москва / Ватутинки)
* Быстрый расчёт маршрута в Яндекс Картах, адаптивные кнопки перехода на YouTube, Rutube и в мессенджеры (Telegram, WhatsApp, ВКонтакте, телефон).

## 🛠️ Стек технологий

* **Frontend-фреймворк**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
* **Сборщик**: [Vite 6](https://vitejs.dev/)
* **3D-графика**: [Three.js](https://threejs.org/) + `OrbitControls`, `GLTFLoader`, GLSL Custom Shaders
* **Стилизация**: [Tailwind CSS v4](https://tailwindcss.com/)
* **Аудио-движок**: Web Audio API + SoundFont Sampler Engine (MusyngKite & FluidR3)
* **Иконки**: [Lucide React](https://lucide.dev/)
* **SEO & Микроразметка**: Schema.org (`LocalBusiness`, `EducationalOrganization`), OpenGraph, Twitter Cards, Sitemap, Robots.txt, Яндекс Вебмастер и Google Search Console мета-теги.

## 🚀 Быстрый старт и запуск проекта

### Требования
* [Node.js](https://nodejs.org/) версии **18.0.0** или выше
* Пакетный менеджер **npm** (или **pnpm** / **yarn**)

### Установка зависимостей
```bash
git clone https://github.com/aaeroha/webp-vocal.git
cd webp-vocal
npm install
```

### Запуск локального сервера разработки
```bash
npm run dev
```
Сервер будет доступен по адресу `http://localhost:5173/`.

### Сборка для продакшена (Production Build)
```bash
npm run build
```
Готовые статические файлы будут скомпилированы в директорию `dist/`.

### Предпросмотр продакшен-сборки
```bash
npm run preview
```

## 📱 Адаптивность и мобильная оптимизация

* **Desktop & Retina**: Полноэкранный WebGL-рендеринг с антиалиасингом, интерактивные всплывающие меню и живые связующие линии.
* **Mobile**:
  * 3D-атлас автоматически переходит в вертикальный режим с чистой верхней сценой, аккуратной сеткой цветных кнопок и подробной карточкой описания снизу.
  * Кнопки социальных сетей и материалов («YouTube», «Rutube») на мобильных экранах выстраиваются в одну ровную строку одинакового размера.
  * Все слайдеры и карусели поддерживают нативный Touch-жест без конфликта с вертикальным скроллом страницы.
